# UI Acceptance Checklist

当前阶段尚未实现前端。后续新增或修改页面后，至少检查：

- [ ] 首页可以正常加载
- [ ] 没有明显控制台错误
- [ ] 可以导入或选择政策文件
- [ ] 文件状态能够正确展示
- [ ] 可以提交政策研究问题
- [ ] 分析期间存在加载提示
- [ ] 三个 Agent 的执行状态可以区分
- [ ] 最终报告章节完整
- [ ] 政策引用可以展示
- [ ] 公司业务匹配没有写成投资建议
- [ ] 空结果有明确提示
- [ ] 工具调用失败时页面不会崩溃
- [ ] 长文本没有明显遮挡或溢出
- [ ] 刷新页面后不会出现严重状态错误
